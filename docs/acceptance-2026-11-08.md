5. 探针冷却和共享探针锁位于 `data_dir`，自定义目录须持久挂载；探针同时持有项目根目录的旧锁。多实例须共享支持操作系统文件锁的数据目录并运行支持共享锁的版本，不同项目目录的旧版本不受共享锁保护；健康快照仍独立存储。实际多容器及跨主机文件系统未验证。
6. 统计与管理密钥均为可选；留空的权限组不鉴权。远程访问还须 TLS、可信反向代理认证及访问控制。历史 Git 截图曾含未遮盖邮箱；当前文件已遮盖，但历史尚未重写，亦未授权强推。
